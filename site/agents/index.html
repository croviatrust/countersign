How it works

Same construction as TACET, our production transparency log: salted fingerprints, a sparse Merkle map, signed sheets, offline verifiers.

1 · Witness

Everything the agent sends is fingerprinted

A witness sits where outbound bytes are visible: Causari's local proxy (re proxy --pnx), your LLM gateway logs, or a CI step. Request bodies are cut into k-grams, hashed with a per-run salt and committed to a sparse Merkle map. The witness signs the run sheet, and an optional reach record lists every destination the run tried to reach under your allowlist.

2 · Prove

Per asset: absent, or exposed

For each protected asset (API keys, customer files, source directories) the prover attaches a non-inclusion path against the run root. If an asset did appear, the same object becomes signed evidence of the exposure. Any shared substring of 47 bytes or more is always detected, including inside JSON request bodies.

3 · Verify

Offline, by anyone, with open code

The auditor gets the proof, a ~kilobyte Crovia Seal, and optionally the assets. Three independent verifiers (Python, JavaScript in the browser, Rust) agree byte for byte on public conformance vectors. The proof contains no traffic bytes and nothing about the assets except their SHA-256.

What a PNX proof does not claim

The limits are part of the specification (PNX §7). We state them before you ask.

Bytes the witness did not see. Traffic that bypassed the witness, TLS it could not read and side channels are outside the proof. The proof is only as complete as the boundary that forces traffic through the witness, and it says which capture was used.
Transformations it does not normalise. Paraphrase, translation, summaries, base64, URL-encoding and UTF-16 are outside the proof. Raw bytes and JSON string values are covered.
Very short assets. Assets under 32 bytes cannot be covered. Assets that are short or only partly covered are reported as undetectable or absent-partial and are never counted as clean.
A single witness is one statement. Countersigning by several independent witnesses (Countersign) removes that single point of trust.
