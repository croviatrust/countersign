<p><strong>Crovia proves what did not happen.</strong> Signed, hourly observations of
what AI model cards disclose about their training data, each hour opened by a public
randomness beacon and closed by a Bitcoin anchor. Verification never needs an account or
a Crovia server. Data CC-BY-4.0, code Apache-2.0.</p>

<ul>
  <li><strong>TACET disclosure ledger</strong> — every observation since 2026-09-19, byte for
  byte, with epoch sheets, anchors and featured silence proofs. Updated hourly from the live log.</li>
  <li><strong>Survival Report</strong> (causari) — weekly: how much AI-tagged code is still at HEAD,
  against the same repository's untagged code of the same age.</li>
  <li><strong>Specifications</strong> — <a href="https://croviatrust.com/registry/tacet/spec/">TACET</a>
  (Internet-Draft <code>draft-crovia-tacet</code>), <a href="https://croviatrust.com/registry/seal/">Crovia Seal</a>.</li>
</ul>

<p>A row that says <code>result: false</code> means <em>no training-data disclosure was found on
that surface in that hour</em> — not a finding of fraud, not a grade, not a claim about what the
provider did elsewhere. Hours not observed count for nothing.</p>
