# Crovia Evidence Lab

[![License: CC BY 4.0](https://img.shields.io/badge/Data-CC_BY_4.0-lightgrey.svg?style=flat-square)](https://creativecommons.org/licenses/by/4.0/)

**Crovia records what AI providers disclose about training data, and the
absence of it, as signed, Bitcoin-anchored facts.** This repository is the
public data plane: datasets exported from the ledger, leaderboards, and
reproducible capsules that let anyone recompute a published figure from the
signed envelopes.

## Contents

```
datasets/      Daily exports (JSONL) of AX.OBS / AX.NEC / AX.ABS envelopes, with the seal they belong to
leaderboards/  Disclosure and silence tables per organisation, regenerated by CI from datasets/
capsules/      One folder per published figure: inputs, script, expected output, OTS proof
```

Every dataset row carries the envelope signature; every leaderboard cell
links to the capsule that produced it; every capsule recomputes to the
published number or CI fails.

## Recompute a figure

```bash
python3 capsules/silence_days/recompute.py --ledger datasets/2026-09-19.jsonl
# prints the same total the site shows, and the merkle root it was sealed under
```

Silence figures follow the canonical definition: days between the first and
the *last* negative observation of a target. They do not grow while
observation is paused, and every figure carries `observed_to`.

## Status

Datasets update daily from the substrate. Leaderboards are regenerated by CI.
Capsules cover the four headline figures of the home page.
